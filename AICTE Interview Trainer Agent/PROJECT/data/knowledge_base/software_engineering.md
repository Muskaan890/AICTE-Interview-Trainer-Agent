# Software Engineering Interview Guide

## Core Technical Topics

### Data Structures & Algorithms
Interview candidates for software engineering roles must demonstrate proficiency in:
- Arrays, Linked Lists, Stacks, Queues
- Trees (Binary, BST, AVL, Red-Black), Graphs
- Hash Maps, Heaps, Tries
- Sorting algorithms (QuickSort O(n log n), MergeSort O(n log n), HeapSort)
- Searching (Binary Search, BFS, DFS)
- Dynamic Programming, Greedy Algorithms, Backtracking
- Time/Space complexity analysis (Big O notation)

Common interview formats: LeetCode-style coding problems, whiteboard coding, pair programming.

### System Design
Senior engineers are expected to design scalable systems:
- Microservices vs Monolith trade-offs
- Load balancing strategies (Round Robin, Least Connections, IP Hash)
- Horizontal vs Vertical scaling
- CAP Theorem (Consistency, Availability, Partition tolerance)
- Caching layers: Redis, Memcached (LRU, LFU eviction)
- Message queues: Kafka, RabbitMQ, IBM MQ
- Database sharding, replication, and indexing
- CDN for static asset delivery
- API design principles (REST, GraphQL, gRPC)

### Object-Oriented Programming
Candidates must demonstrate mastery of OOP concepts:
- SOLID Principles (Single Responsibility, Open/Closed, Liskov Substitution, Interface Segregation, Dependency Inversion)
- Design Patterns: Singleton, Factory, Observer, Strategy, Decorator, Command
- Inheritance vs Composition
- Polymorphism and abstraction

## Common Interview Questions for Software Engineers

### Technical Round
1. Explain the difference between a process and a thread.
2. What is deadlock? How do you prevent it?
3. Describe how a hash table works and its time complexity.
4. Design a URL shortener service (TinyURL clone).
5. Implement LRU Cache with O(1) get and put operations.
6. Explain REST vs GraphQL. When would you use each?
7. What is eventual consistency? Give a real-world example.
8. Describe your approach to debugging a memory leak in production.

### Experience Level Expectations
- **Fresher**: Basic data structures, algorithms, one language proficiency, simple OOP
- **Junior (1-2 yrs)**: CRUD applications, basic system design, debugging skills
- **Mid-Level (3-5 yrs)**: Distributed systems awareness, performance optimization, code reviews
- **Senior (6-9 yrs)**: Full system design, architectural decisions, team leadership, mentoring
- **Lead/Principal (10+ yrs)**: Org-wide technical strategy, cross-team dependencies, innovation

## Industry Expectations (2024-2025)
- Cloud-native development is standard expectation
- DevOps knowledge (CI/CD, containerization) valued at all levels
- AI/ML integration increasingly expected even for backend roles
- Security-by-design mindset required for most companies
- IBM Cloud, AWS, Azure certifications add significant value
